# 💰 Expense Tracker

A modern desktop Expense Tracker application built with **Python** and **CustomTkinter** to help users manage daily expenses efficiently.

This application provides a clean graphical interface where users can add, edit, update, delete, search, filter, and visualize expenses using charts. All expense data is automatically saved and loaded using CSV files.

---

## ✨ Features

- ➕ Add new expenses
- ✏️ Edit existing expenses
- 🔄 Update expense details
- 🗑️ Delete expenses
- 🔍 Search expenses
- 🧹 Clear Search
- 📂 Filter expenses by category
- 📊 Dashboard Cards
  - Total Expense
  - Total Records
  - Total Categories
- 🥧 Pie Chart Visualization
- 📈 Bar Chart Visualization
- 💾 Automatic CSV Save
- 📂 Automatic CSV Load
- 🌙 Modern Dark Theme Interface
- 🖥️ User-friendly Desktop GUI

## 🚀 Installation

### Clone the repository

```bash
git clone https://github.com/dhruvkr4178-sketch/Expense-Tracker.git
```

### Open the project folder

```bash
cd Expense-Tracker
```

### Install dependencies

```bash
pip install customtkinter matplotlib
```

### Run the application

```bash
python gui.py
```

---

## 💻 Windows Executable

A standalone Windows executable (**Expense Tracker.exe**) can also be generated using **PyInstaller**, allowing users to run the application without installing Python.
