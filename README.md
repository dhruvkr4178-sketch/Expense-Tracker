# Expense Tracker

A simple and user-friendly Expense Tracker built using Python and CustomTkinter. This application allows users to add and manage daily expenses through a modern graphical user interface.

## Features

- Add new expenses
- Store Date, Category, Description, and Amount
- Display expenses in a table
- Dark Theme GUI
- Easy-to-use interface

## Technologies Used

- Python 3
- CustomTkinter
- Tkinter (Treeview)

## Project Structure

```
Expense Tracker/
│── gui.py
│── main.py
│── README.md
```

## How to Run

1. Clone the repository

```
git clone https://github.com/YOUR_USERNAME/expense-tracker.git
```

2. Open the project folder

3. Install CustomTkinter

```
pip install customtkinter
```

4. Run the project

```
python gui.py
```
